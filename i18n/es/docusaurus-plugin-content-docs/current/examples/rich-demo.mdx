# Demo completa

**Archivo:** `examples/rich_demo_agent.py`

Demo de traza de máxima fidelidad. Combina un turno del modelo, reintentos de herramientas, comandos de shell, lecturas y escrituras de archivos, parches, artefactos y decisiones derivadas en una sola ejecución.

## Ejecutar

```bash
uv run examples/rich_demo_agent.py
```

## Qué demuestra

- Turnos del modelo con selección de herramientas
- Reintentos de herramientas y gestión de errores
- Ejecución de comandos de shell con códigos de salida
- Operaciones de lectura y escritura de archivos
- Aplicación de parches
- Generación de artefactos
- Decisiones derivadas de los resultados de las herramientas

## Cuándo usarlo

Usa este ejemplo cuando quieras la **ejecución más densa posible** para inspeccionar el panel, la línea de tiempo y las vistas de artefactos. Ejercita todos los tipos de evento que admite TraceAgent.
