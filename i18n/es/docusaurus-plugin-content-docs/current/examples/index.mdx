# Ejemplos

TraceAgent incluye varios ejemplos ejecutables. Asegúrate de que el servidor está en marcha en `http://127.0.0.1:8000` antes de ejecutar cualquiera de ellos.


:::info

La mayoría de los scripts cargan la configuración desde un archivo `.env` local, así que es el lugar más cómodo para definir la URL del backend y los ajustes del modelo.

:::

## Requisitos previos

Instala desde el código fuente con los extras de desarrollo:

```bash
uv sync --extra dev --extra providers --extra langchain
```

## Ejecutar los ejemplos

Todos los ejemplos siguen el mismo patrón:

```bash
uv run examples/<script_name>.py
```

Algunos ejemplos aceptan opciones de línea de comandos como `--scenario` o `--prompt`. Consulta la página de cada ejemplo para ver los detalles.
