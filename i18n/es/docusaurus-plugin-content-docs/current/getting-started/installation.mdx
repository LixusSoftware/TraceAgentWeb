# Instalación

TraceAgent requiere **Python 3.11+** (probado en 3.11 a 3.14) y se puede instalar con pip o uv, con Docker o desde el código fuente.

## Instalar con pip o uv

Cada paquete se puede instalar de forma independiente, con `pip` o con [uv](https://docs.astral.sh/uv/):

TraceAgent se compone de cinco paquetes: `trace-agent-sdk`, `trace-agent-server`, `trace-agent-langchain`, `trace-agent-pydantic-ai` y `trace-agent-ui`. El paquete de Pydantic AI requiere Pydantic AI 2.x. Si trazas mediante [OpenTelemetry](/es/docs/instrumentation/opentelemetry), no necesitas ningún paquete de TraceAgent en el agente, solo en el servidor.

:::note[uv add frente a uv pip install]
`uv add` añade los paquetes al `pyproject.toml` de tu proyecto y los instala. Si solo quieres instalar en un entorno existente sin proyecto, usa `uv pip install`.
:::

:::tip
Si solo necesitas **instrumentar** tu agente (y el servidor se ejecuta en otro sitio), instala únicamente el SDK. El servidor y la UI solo hacen falta para el backend autoalojado.
:::

## Docker

Hay imágenes ya construidas para el backend y el frontend:

| Componente | Imagen |
|-----------|-------|
| TraceAgent Server | `ghcr.io/lixussoftware/trace-agent-server:0.5.0` |
| TraceAgent UI | `ghcr.io/lixussoftware/trace-agent-ui:0.5.0` |

```bash
# Descarga las imágenes
docker pull ghcr.io/lixussoftware/trace-agent-server:0.5.0
docker pull ghcr.io/lixussoftware/trace-agent-ui:0.5.0
```

Para una configuración completa con Docker Compose, consulta la **[guía de despliegue con Docker](/es/docs/configuration/docker)**.

## Desde el código fuente

```bash
git clone https://github.com/LixusSoftware/TraceAgent.git
cd TraceAgent
```

<Tabs>
  <TabItem value="uv" label="uv (recomendado)" default>

```bash
uv sync --extra dev --extra providers --extra langchain --extra pydantic-ai
```

  </TabItem>
  <TabItem value="pip" label="pip">

```bash
pip install -e ".[dev,providers,langchain]"
```

  </TabItem>
</Tabs>

## Verificar la instalación

```bash
python -c "from trace_agent_sdk import TraceAgentClient; print('TraceAgent SDK ready ✓')"
```
