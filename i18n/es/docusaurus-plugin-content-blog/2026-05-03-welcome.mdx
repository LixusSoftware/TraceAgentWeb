# Te damos la bienvenida a TraceAgent

Estamos encantados de presentar **TraceAgent**, una plataforma de observabilidad y trazabilidad de código abierto creada específicamente para agentes de IA.

{/* truncate */}

## Por qué lo creamos

Las herramientas de observabilidad tradicionales se diseñaron para microservicios y aplicaciones web. Entienden las peticiones HTTP, las consultas a bases de datos y los mensajes de las colas. Pero no entienden qué significa que un agente de IA:

- **Llame a una herramienta** y decida qué hacer con el resultado
- **Escriba un archivo** y luego lo lea de nuevo para verificarlo
- **Reintente un comando fallido** con otra estrategia
- **Encadene varias decisiones** a lo largo de un flujo de planificación complejo

TraceAgent cubre ese hueco con una **especificación de trazabilidad pensada para agentes** y una interfaz de visualización hecha a medida.

## Qué puedes hacer hoy

- 📦 **Instala el SDK** y empieza a trazar en minutos
- 🔗 **Conecta agentes de LangChain** con un único callback
- 📊 **Visualiza la ejecución** con líneas de tiempo interactivas
- 🏠 **Autoaloja todo**: control total de tus datos

## Primeros pasos

La forma más rápida de empezar:

```bash
pip install trace-agent-sdk
# o, con uv
uv add trace-agent-sdk
```

Después ve a nuestra [guía de inicio rápido](/es/docs/getting-started/quick-start) para crear tu primera traza en menos de 5 minutos.

## Qué viene después

Danos una estrella en [GitHub](https://github.com/LixusSoftware/TraceAgent) y sigue las novedades.
