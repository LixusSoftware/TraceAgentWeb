# Installation

TraceAgent requires **Python 3.11+** (tested on 3.11, 3.12 and 3.13) and can be installed via pip or uv, Docker, or from source.

## Install via pip or uv

Each package can be installed independently, with `pip` or with [uv](https://docs.astral.sh/uv/):

  <TabItem value="all" label="All Packages" default>

  <TabItem value="sdk" label="SDK Only">

<PackageInstall packages={['trace-agent-sdk']} />

TraceAgent is made of five packages: `trace-agent-sdk`, `trace-agent-server`, `trace-agent-langchain`, `trace-agent-pydantic-ai` and `trace-agent-ui`. The Pydantic AI package requires Pydantic AI 2.x. If you trace through [OpenTelemetry](/docs/instrumentation/opentelemetry) instead, you don't need any TraceAgent package in the agent, only on the server.

:::note[uv add vs uv pip install]
`uv add` adds the packages to your project's `pyproject.toml` and installs them. If you just want to install into an existing environment without a project, use `uv pip install` instead.
:::

:::tip
If you only need to **instrument** your agent (and the server runs elsewhere), install just the SDK. The server and UI are only needed for the self-hosted backend.
:::

## Docker

Pre-built images are available for the backend and frontend:

| Component | Image |
|-----------|-------|
| TraceAgent Server | `ghcr.io/lixussoftware/trace-agent-server:latest` |
| TraceAgent UI | `ghcr.io/lixussoftware/trace-agent-ui:latest` |

```bash
# Pull the images
docker pull ghcr.io/lixussoftware/trace-agent-server:latest
docker pull ghcr.io/lixussoftware/trace-agent-ui:latest
```

For a full Docker Compose setup, see the **[Docker deployment guide](/docs/configuration/docker)**.

## From Source

```bash
git clone https://github.com/LixusSoftware/TraceAgent.git
cd TraceAgent
```

<Tabs>
  <TabItem value="uv" label="uv (recommended)" default>

```bash
uv sync --extra dev --extra providers --extra langchain --extra pydantic-ai
```

  </TabItem>
  <TabItem value="pip" label="pip">

```bash
pip install -e ".[dev,providers,langchain]"
```

  </TabItem>
</Tabs>

## Verify Installation

```bash
python -c "from trace_agent_sdk import TraceAgentClient; print('TraceAgent SDK ready ✓')"
```
